## 📖 Sobre o projeto

O **System Or Shirt Studio** é uma aplicação web estática que tem como objetivo oferecer uma experiência interativa para criação e personalização de camisetas diretamente no navegador, sem necessidade de instalação ou backend.

O projeto faz parte do ecossistema **OR System**, marca sob a qual são desenvolvidas soluções digitais focadas em usabilidade, design limpo e funcionamento offline-first.

### 🎯 Problema que resolve

["Permitir que clientes visualizem e personalizem camisetas antes de comprar, sem depender de software instalado." ou "Oferecer uma ferramenta de demonstração de estampas para lojistas."]

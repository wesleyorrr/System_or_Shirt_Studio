## 📖 Sobre o projeto

O **System Or Shirt Studio** é uma aplicação web que permite ao usuário personalizar camisetas em tempo real, visualizando o resultado antes de qualquer compra. O projeto foi construído como parte do ecossistema **OR System**, marca voltada a soluções digitais com foco em **simplicidade, performance e funcionamento offline-first**.

### 🎯 Problema que resolve

Permitir que **clientes e lojistas** visualizem e personalizem camisetas antes de comprar, sem depender de softwares instalados ou de um servidor backend.

### 👥 Público-alvo

- Pequenos lojistas de vestuário
- Clientes finais da marca
- Uso interno da OR System (demonstração de estampas)

---

## ✨ Funcionalidades

- Personalização de camisetas em tempo real no navegador 🎨
- Pré-visualização do produto antes da compra
- Interface responsiva e leve, sem dependências externas
- Funcionamento **offline-first** (sem necessidade de backend)
- Estrutura modular em HTML, CSS e JavaScript puro

---

## 🚀 Tecnologias Utilizadas

- **HTML5** — estrutura semântica
- **CSS3** — layout responsivo e estilização
- **JavaScript Vanilla** — lógica de personalização e interatividade
- **GitHub Pages** — deploy estático

---

## 🧠 Decisões técnicas & aprendizados

- **Vanilla JS em vez de frameworks**: escolha consciente para manter o bundle leve, o carregamento rápido e o código acessível a qualquer dev que for dar manutenção.
- **Arquitetura estática**: sem backend, o que reduz custo de hospedagem e simplifica o deploy via GitHub Pages.
- **Separação de responsabilidades**: `index.html` (estrutura), `style.css` (apresentação) e `script.js` (comportamento) organizados de forma clara.
- **Offline-first**: a aplicação continua funcional sem conexão após o primeiro carregamento.
